1 token — the unit the models are billed in

Not a letter, not a word: a chunk the model was trained to see as one thing.

THE SAME 100 BYTES, CUT INTO TOKENS
English prose
31 tokens
Japanese
34 tokens
a shell command
67 tokens
DNA, 101 bp
98 tokens
a quality line
95 tokens
Measured with Anthropic’s token counter on 18 Sep 2026. More pieces for the same bytes means more to pay for.
English: about 3–4 bytes a token. That is the number people quote. It is a number about English.
Your data: about 1 byte a token. ATGC is not a word. Sequence and quality lines are cut almost one token per character — three times the price of prose, byte for byte.
so, one FASTQ file hal_L_C.fastq is 134 MB → about 134 million tokens: 134× the largest context window there is, and some 400 dollars at 3 dollars a million. You do not paste data at an agent. You give it a command that reads the data.
There is no fixed answer. Every vendor trains its own tokenizer, so the same file is a different number of tokens at Anthropic, at OpenAI, at Google — and different again on their next model. Count it; do not assume it.

THE x BIT — ls -l

-rwxrwxr-x  myscript.sh
Three x: you, your group, everyone else.
THE SHEBANG — FIRST LINE, FIRST TWO CHARACTERS
#!/bin/bash
echo hello
Names the program that reads the rest. Leave it out and bash runs the file itself — which works here and will not somewhere else.
and the way round all three bash myscript.sh needs no chmod, no ./ and no shebang — you named the interpreter yourself. That is how every script in this course is run.
chmod +x does not make a file a program. It gives the kernel permission to try.

Practical Shell Script Example

#!/bin/bash
# process_files.sh - Process FASTQ files

# Set variables
INPUT_DIR="$1"

# Process each FASTQ file
for file in "$INPUT_DIR"/*.fastq; do
    if [ -f "$file" ]; then
        filename=$(basename "$file" .fastq)
        echo "Processing $filename..."
        
        # Count reads and save to output
        read_count=$(grep -c "^@" "$file")
        echo "$filename: $read_count reads" >> summary.txt
    fi
done
